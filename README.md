# Dulce Hornero - Landing Page (Tailwind CSS 4 & IA)

Proyecto práctico individual de desarrollo frontend para la asignatura de Ingeniería de Software / Seminario Ágil en la Fundación Escuela Tecnológica de Neiva "Jesús Oviedo Pérez" (FET).

## 🛠️ Tecnologías y Herramientas Utilizadas
- **HTML5** (Estructura semántica con accesibilidad WCAG)
- **Tailwind CSS v4** (Mediante Play CDN, directiva `@theme` y paleta personalizada)
- **JavaScript Puro** (Validación de formularios, menú móvil responsive, acordeón FAQ y modo oscuro)
- **Google Fonts** (Playfair Display e Inter)
